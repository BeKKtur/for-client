# 💗 Второй шаблон романтической страницы

Это отдельный дизайн, не похожий на первый вариант.

## Быстрый запуск

Открой `index.html` в браузере.

## Самое главное

Открой `script.js`.

В самом начале есть:

```js
const config = {
  name: "Имя девушки",

  texts: {
    ...
  },

  colors: {
    ...
  }
};
```

### Имя

```js
name: "Алина"
```

### Тексты

Все тексты страницы находятся в `texts`.

### Цвета

Например:

```js
primary: "#e9a0bb",
background: "#120d18",
text: "#fff4f7"
```

Можно заменить их на любые HEX-цвета.

## Функционалы

- персональное имя;
- интерактивное письмо;
- раскрывающиеся причины;
- секретный блок;
- кнопка «Я тебя люблю»;
- анимация сердечек;
- звёздный фон;
- светлая/тёмная тема;
- сохранение темы;
- адаптация под телефон;
- все настройки в одном месте.

Музыки, галереи и счётчика отношений нет.
